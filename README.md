# 🌱 Greeny — Sustainable Community Website

Greeny is a modern, responsive sustainability website built with **React** and **Tailwind CSS**. It focuses on tree planting, environmental projects, community impact, sustainable development, and collaboration for organizations.

## ✨ Features

- Fully responsive design
- Mobile, tablet, and desktop support
- Modern editorial-style UI
- Smooth scrolling
- Scroll reveal animations
- Animated tree and nature elements
- Interactive navigation menu
- Responsive hero sections
- Programs slider
- Community stories slider
- Smooth story transitions
- FAQ accordion
- Awards and recognition section
- Interactive hover effects
- Newsletter subscription UI
- Back-to-top button
- Responsive image sections
- Interactive planting map page
- Verified projects detail page
- Organization collaboration tools page
- React Router navigation
- Dedicated insight/detail pages
- Reusable React components

## 🛠️ Tech Stack

- React
- Tailwind CSS
- Vite
- JavaScript (ES6+)
- Lucide React
- React Router DOM
